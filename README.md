#### Bistro Bliss is a user-friendly web app designed for restaurant lovers. It lets you explore the restaurant’s menu, book a table easily, and create an account to keep track of your bookings. Bistro Bliss makes dining out simple and stress-free!


# Features

#####  __For Users:__

- __Create and Manage Accounts:__ Users can sign up, log in, and update their profile information anytime.
- __View Menu:__ Easily browse the restaurant’s menu with all available items and details.
- __Book a Table:__ Make table reservations quickly and conveniently through the app.
- __Manage Bookings:__ View and track all your bookings directly from your profile.

##### __For Admins:__

- __Menu Management:__ Admins can add, update, or delete menu items to keep the menu up-to-date.
- __User Management:__ View and manage all users registered on the platform.
- __Booking Management:__ See all user bookings, approve or decline table reservations based on availability or other factors.
- __Site Administration:__ Oversee and control the platform to ensure smooth operation.

# Run Locally

#### __Clone the project__

```bash
  git clone https://github.com/AliiMuhammed/Final-Project-Amit.git
```
###### __To run Client side & Server Side__:

- Go to the Clinet directory
    ```bash
        cd Final-Project-Amit\bistro
    ```
- And for Server directory Go to
    ```bash
        cd Final-Project-Amit\server
    ```
- Install dependencies

    ```bash
        npm install
    ```

- Start Node server

    ```bash
        npm run start
    ```
